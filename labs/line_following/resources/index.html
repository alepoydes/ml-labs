Line Following: 50 training and 15 validation courses

Blue: start and return finish. Red: far turnaround. Follow the entire open route to red and back to blue. Each drawing has its own scale; line width is always 11.75 mm. The first two training courses share a straight route with different robots.

Begin with training cases in order, then mix them and prepare extra training cases. Validation uses separate geometry. To reproduce a fixed episode, select its case identifier in the graphical runner, with Batch set to 1. Robot parameters, initial state and sensor noise are fixed by the case. An extra diagnostic case uses train-04 geometry with another robot.
