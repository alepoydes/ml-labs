# Planned laboratories

These four assignments are not yet implemented. Their detailed contracts and
metrics will be agreed before release, and they do not contribute to current totals.

| Lab | Direction | Decisions still open |
| --- | --- | --- |
| Terrain robot | Reinforcement learning and control on uneven terrain; PID baseline; distance and then speed | Simulator, scenarios, robot geometry, exact scoring |
| Synthetic trading | Sequence models trading an unknown synthetic stochastic process using available history | Actions, positions, costs, market rules, scoring |
| Generative modeling | Diffusion models; supporting VAEs, GANs, mixtures, and density estimation | Dataset, generation interface, metric |
| Language models | Small transformers; possible translation of English instructions into grid-painting programs | Language, world model, dataset, executable evaluation |

The language-model grid-painting robot is separate from the terrain robot.
