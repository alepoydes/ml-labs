# Planned laboratories

These four assignments do not contribute to current totals. Line Following has
a task description and a public dynamics prototype; tracks, sensors, evaluation,
and final numerical settings remain pending. These details will be published
before assessment. The other three assignments are not yet implemented.

| Lab | Direction | Decisions still open |
| --- | --- | --- |
| Line Following | Learned control and adaptation on flat ground; a balancing robot follows a line out and back in one timed episode | Tracks, sensors, evaluation, calibrated physical settings, controller interface, scoring |
| Synthetic trading | Sequence models trading an unknown synthetic stochastic process using available history | Actions, positions, costs, market rules, scoring |
| Generative modeling | Diffusion models; supporting VAEs, GANs, mixtures, and density estimation | Dataset, generation interface, metric |
| Language models | Small transformers; possible translation of English instructions into grid-painting programs | Language, world model, dataset, executable evaluation |

The language-model grid-painting robot is separate from the line-following robot.
